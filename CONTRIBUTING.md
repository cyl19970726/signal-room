# Contributing

Signal Room is specification-first and evidence-first.

Before implementing a feature:

1. Link it to an accepted requirement or open a proposal.
2. Preserve platform, provenance, null, evidence, and review boundaries.
3. Do not add real creator media, browser state, cookies, signed URLs, or private datasets.
4. Add tests for schema and failure behavior.
5. For UI changes, update the UX specification before code when the design intent changes.

Bug reports should include a redacted reproduction, expected behavior, actual behavior, and adapter/app version. Never paste authentication material.
